# Dictionarry Docs

Documentation site for the Dictionarry ecosystem.

## Prerequisites

- [Node.js](https://nodejs.org/) >= 22.13
- [pnpm](https://pnpm.io/) >= 11

## Getting Started

```bash
git clone https://github.com/Dictionarry-Hub/website.git
cd website
git checkout develop
pnpm install
pnpm dev
```

The dev server runs at `http://localhost:5173`.
